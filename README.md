# 超休闲游戏关卡设计与 AI 管线内部指南

**战略研究部 · 创新组 · 内部指南文档 · v1.1.0**

---

## 文档用途

用于战略研究部创新组理解休闲 / 超休闲 IAA 游戏设计方法，并将竞品拆解、算法分析、参数化生成、AI 管线和数据反馈转化为可复用的 AI 全栈开发工作流。

## 适用对象

- 战略研究部
- 创新组
- 参与休闲 / IAA / AI 全栈开发探索的同学
- 需要了解超休闲设计与 AI 管线的内部成员

## 核心内容摘要

- 超休闲游戏核心设计理念
- 行业通用产品开发流程
- 指标适用边界
- 竞品四层拆解方法论
- 人工→AI 管线映射（含二合类管线）
- AI 落地阶段路线
- 创新组落地方案：单人策划 + AI 工具链
- 品类选择：二合类为当前推荐，排序类为算法验证方向
- 工具栈与组织模式
- 创新组一页执行版

## 如何本地打开

直接双击 `index.html`，或使用浏览器打开。无需任何网络连接或服务器环境。

## 如何用于 Netlify 部署

将整个 `share_hyper_casual_game_design_guide/` 文件夹上传 / 拖拽到 Netlify Deploy，即可生成可分享页面。Netlify 将自动识别 `index.html` 作为首页。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 可独立打开和部署的主文档，所有 CSS 内嵌 |
| `README.md` | 本文档 |
| `manifest.json` | share 包元信息 |
| `assets/` | 资源目录（当前版本无外部依赖资源） |

## 注意事项

- 当前 share 包不依赖本地绝对路径
- 当前 share 包不依赖外部 CDN
- 如果后续修改主 HTML（`hyper_casual_game_design_guide.html`），需要同步覆盖 share 包中的 `index.html`
